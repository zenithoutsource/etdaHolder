Holder

คือคุณ กด NFC บนใบขับขี่ แล้ววางมือถือบนเครื่องอ่าน ต้องการรู้ว่าจะส่งข้อมูลอะไร และไม่อยากส่งทั้งใบโดยไม่รู้ตัว

Wallet

เก็บใบขับขี่ดิจิทัล (mdoc) ไว้ในเครื่อง เป็นคนตัดสินใจว่า จะส่งช่องไหนออกไป ตามกฎที่ล็อกไว้

Verifier

เจ้าหน้าที่หรือเว็บที่ต้องการตรวจตัวตน ส่งคำขอผ่านเครื่องอ่าน ไม่ได้ดึงข้อมูลจาก Wallet ตรง ๆ ผ่านอินเทอร์เน็ต

เปรียบง่าย ๆ Holder คือเจ้าของแฟ้ม · Wallet คือตู้เซฟที่เปิดช่องได้ทีละใบ · Verifier คือเจ้าหน้าที่ที่ยื่นใบรายการว่าอยากดูอะไร

คำถามที่พบบ่อย

“เพราะเป็น NFC เลยขอมาในการแตะครั้งเดียวไม่ได้?”

เกือบถูก แต่ยังคลาด

ความเข้าใจนี้คิดว่าเครื่องอ่าน ส่งคำขอมาไม่ได้ ในครั้งเดียว เลยต้องให้คนถือวางมือถืออีกรอบ เพื่อให้ Wallet ได้เห็นคำขอ

ที่เป็นจริง

คำขอมาได้ใน hold เดียว และมาครบ ปัญหาไม่ใช่ “คำขอมาไม่ทัน” แต่เป็น “คนดูจอไม่ทัน” เพราะตอนคำขอมา มือถือกำลังคว่ำบนเครื่องอ่านอยู่

เปรียบเหมือนสั่งอาหารตอนวางมือถือคว่ำ พนักงานยื่นเมนูมาได้ตอนคุณวางมือถือทับใบเสร็จแล้ว คุณอ่านเมนูไม่ทัน ไม่ได้แปลว่าครัวส่งเมนูไม่ได้ — แปลว่าคุณเลือกอาหารไม่ทันในวินาทีนั้น เลยต้องเลือกเมนู ก่อน จะวางมือถือ

ทางเลือกที่เราไม่เลือก

ถ้าอยากให้คนเห็นคำขอสด ต้องทำอย่างอื่น

แบบ Apple / Google (มักใช้ BLE)

แตะสั้น ๆ เพื่อเริ่มคุย จากนั้นย้ายไปบลูทูธ ยกมือถือขึ้นมาได้ จอโชว์ว่าเขาขออะไร กดยินยอม แล้วข้อมูลวิ่งทางบลูทูธ

ข้อดี: เห็นคำขอจริง · ข้อแลก: โปรเจกต์นี้ยังไม่เปิด BLE สำหรับเส้นนี้

แบบแตะสองครั้ง

แตะครั้งที่ 1 ให้เครื่องอ่านส่งคำขอมา → ยกเครื่องขึ้นมาดูจอ → กดยินยอม → แตะครั้งที่ 2 เพื่อส่งคำตอบ

ข้อแลก: คนถือสับสน เครื่องอ่านหลุดง่าย ไม่ใช่แนวทางที่ล็อกไว้สำหรับ v1

เลยเลือกทางที่สาม รู้ล่วงหน้าว่าเครื่องอ่านตัวนี้ (ACR1311 + เว็บนี้) ขอได้สูงสุดแค่ 3 ช่อง ให้คนกดยินยอม 3 ช่องนั้นตอนมือถือยังอยู่ในมือ แล้วค่อยวางแตะครั้งเดียวให้จบ
เพดาน (ceiling)

จอยินยอมก่อนแตะ คือ “สูงสุดที่เครื่องนี้ขอได้”

ไม่ใช่ใบขับขี่ทั้งใบ และยังไม่ใช่คำขอสดจากเครื่องอ่าน คือรายการที่ Wallet ยอมให้เครื่องอ่านโปรไฟล์นี้ขอได้

นามสกุล (family_name) ชื่อ (given_name) วันเกิด (birth_date)

กดยินยอม

แปลว่า “ถ้าเครื่องอ่านขอช่องในสามช่องนี้ ส่งได้” จากนั้น Wallet เปิด NFC พร้อมรอแตะ

กดไม่ยินยอม

ไม่เปิด NFC กลับไปหน้าใบขับขี่ บันทึกประวัติว่าปฏิเสธ ไม่มีการส่งข้อมูล

ไม่มีปุ่มติ๊กเอาช่องใดช่องหนึ่งออก เพราะทั้งสามช่องเป็นชุดตรวจตัวตนของเครื่องอ่านนี้ ถ้าติ๊กวันเกิดออก เครื่องอ่านมักตรวจไม่ผ่านอยู่ดี

ตัวอย่างเดินเรื่อง

สมมติคุณชื่อ สมชาย ไปจุดตรวจ

  1. ใน Wallet มีใบขับขี่ทั้งใบ: ชื่อ นามสกุล วันเกิด รูป เลขใบ ที่อยู่ ประเภทใบ ฯลฯ
  2. คุณกด NFC → จอขึ้นว่าเครื่องอ่านนี้ต้องการ ชื่อ นามสกุล วันเกิด
  3. คุณอ่านแล้วกด “รับทราบและยินยอมส่งข้อมูล”
  4. จอเปลี่ยนเป็น “วางมือถือบนเครื่องอ่าน” ไม่โชว์รายการช่องอีก
  5. คุณวางมือถือค้างไว้ครั้งเดียว
  6. เว็บ Verifier ได้ชื่อ นามสกุล วันเกิด — ไม่ได้รูป ไม่ได้ที่อยู่
  7. Wallet โชว์หน้าสำเร็จว่าส่งไปสามช่องนี้
ตรงไหนที่คนถือ “เลือก” ได้ เลือกได้แค่ว่าจะเข้าสู่การแตะหรือไม่ (ยินยอมทั้งชุด / ปฏิเสธ) ไม่ได้เลือกทีละช่องตอนยืนอยู่หน้าเครื่องอ่าน
Selective disclosure คืออะไร

อย่าส่งทั้งแฟ้ม ถ้าเขาขอแค่สามแผ่น

เปรียบแฟ้มใบขับขี่ ใบจริงในกระเป๋าสตางค์พลิกให้เขาเห็นทั้งใบ ใบดิจิทัลแบบ mdoc เก็บแต่ละช่องเป็นแผ่นแยก เซ็นกำกับทีละแผ่น Wallet ส่งได้ทีละแผ่น โดยไม่ต้องถ่ายทั้งแฟ้ม

ในแฟ้มมีหลายช่อง เช่น:

นามสกุล ชื่อ วันเกิด รูปถ่าย ที่อยู่ เลขใบขับขี่ วันหมดอายุ

Selective disclosure = ส่งเฉพาะแผ่นที่ตกลงจะให้ แผ่นอื่นยังอยู่ในโทรศัพท์ Verifier ไม่ได้เห็นค่า ของแผ่นที่ไม่ส่ง

คนละชั้น 3 แบบ

คำว่า SD คนละความหมาย — เลยงง

ชั้น 1 · Verifier ขอชุดย่อย

เว็บผู้ตรวจตั้งไว้แล้วว่าจุดนี้ขอแค่ชื่อ นามสกุล วันเกิด ไม่ได้ขอรูปหรือที่อยู่ นี่คือการลดข้อมูลฝั่งผู้ตรวจ

เกิดที่: เว็บ / เครื่องอ่าน ตอนสร้างคำขอ

ชั้น 2 · โปรโตคอล mdoc

ตอนตอบ Wallet ใส่ในซองแค่ช่องที่ถูกขอและอยู่ในเพดาน ช่องอื่นไม่ถูกแพ็กไปด้วย แม้ใบในเครื่องจะมีครบ

เกิดที่: โทรศัพท์ ตอน DeviceResponse

ชั้น 3 · ติ๊กในจอ Holder

แบบ OID4VP ออนไลน์: มีรายการเคลมให้เปิด/ปิด เส้น NFC นี้ไม่มีชั้นนี้ คนถือยินยอมทั้งเพดาน

เกิดที่: ไม่เกิดบน NFC tap-only

จำสองประโยคนี้ก็พอ

1. ทำไมยินยอมก่อนแตะ

NFC ส่งคำขอมาในครั้งเดียวได้ แต่มาตอนวางเครื่องอยู่ ดูจอแล้วกดไม่ทัน เลยให้ยินยอมเพดาน 3 ช่องตอนมือถือยังอยู่ในมือ แล้วแตะครั้งเดียวให้จบ

2. SD อยู่ตรงไหน

เว็บเลือกว่าจะขอช่องไหน · โทรศัพท์ตัดของที่ไม่ขอและของนอกเพดาน คนถือไม่ได้ติ๊กทีละช่องบน NFC นี้ แต่ทั้งใบก็ไม่ได้ถูกส่งออกไป
